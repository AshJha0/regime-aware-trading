# Capacity evaluation

Generated by `python tools/evaluate_capacity.py`. Do not edit by hand; rerun the tool.

**The book is synthetic, and ADV and spreads are assumptions.** The bundled instruments have no real volume or quotes, so every dollar figure below follows from the inputs listed here and says nothing about a real market. Read this page for the shape of the curve and how it moves with the inputs, not as a capacity estimate.

## Model

Cost per instrument per day, from `regime.costs`: `half_spread * |dw| * AUM + Y * sigma_daily * sqrt(|trade| / ADV) * |trade|`, with `trade = dw * AUM`. This is opt-in and separate from `run_backtest`, so no pinned number changes.

| Input | Trend instruments | Currency instruments | Source class |
|---|---|---|---|
| Half spread | 1 bps | 0.5 bps | Illustrative, not calibrated |
| ADV | $5bn | $20bn | Illustrative, not calibrated |
| Y | 1 | 1 | Illustrative, not calibrated |
| Daily sigma (mean) | 1.23% | 0.64% | Measured on the synthetic window |


Window t >= 504. AUM is fixed, and each day's trade fills in that day, so carry rebalances pay for one large print. The square-root form is a general rule of thumb. Where peak participation passes 100% of ADV the formula is outside anything it could describe, and those rows are a warning, not a forecast. The halving search runs to $100bn, past the table, so a halving figure above $10bn is an extrapolation of the formula and nothing more.
